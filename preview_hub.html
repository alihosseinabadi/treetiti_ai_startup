Treetiti – All Pages (preview hub)

Full Vite React run needs node/npm (not installed here) and the FastAPI backend needs Postgres+pgvector. This hub runs on Python only and lists every route with its source file + live stub API. Use it to click through all pages.

1. Main site treetiti/ – public

  • / CinematicHome – treetiti/src/components/cinematic/CinematicHome.tsx
  • /start Project Discovery – treetiti/src/pages/StartPage.tsx
  • /privacy – treetiti/src/pages/Privacy.tsx
  • /terms – treetiti/src/pages/Terms.tsx
  • /cookies – treetiti/src/pages/Cookies.tsx
  • 5 langs: treetiti/src/i18n/en,fa,ru,ar,tr.ts – switch via navbar (en default, fa/ar RTL)

2. Admin CRM /admin/* (10 pages)

  • /admin – Dashboard treetiti/src/app/admin/Dashboard.tsx
  • /admin/inbox, /admin/leads, /admin/clients, /admin/projects, /admin/invoices, /admin/contracts, /admin/meetings, /admin/partners, /admin/settings, /admin/login
  • Run: cd treetiti_repo/treetiti && npm install && npm run dev → http://localhost:5173

3. AI Marketing OS dashboard treetiti-ai-os/frontend (8 pages)

  • /login – treetiti-ai-os/frontend/src/pages/Login.tsx
  • / (Dashboard), /chat, /agents, /models, /content, /leads, /memory – see src/App.tsx:76-94
  • API base now env: VITE_API_URL (fixed). Run: cd treetiti-ai-os/frontend && npm install && npm run dev

4. Backend API (stub live now, real needs Postgres)

  • /api/v1/health – live stub
  • /api/v1/agents – 11 agents
  • /api/v1/memory/categories
  • Real: cd treetiti-ai-os/backend && pip install -r requirements.txt && uvicorn app.main:app → localhost:8000/docs

5. Customer platform customer_treetiti/

  • POST /api/v1/onboard {link, q1..q5} → customer_treetiti/directory_router.py
  • GET /api/v1/directory/{id} – dossier
  • Blueprint: customer_treetiti/CUSTOMER_SERVICE_DIRECTORY.md

6. Source file browser

Browse raw sources from this server root: / – e.g. /treetiti/src/App.tsx, /treetiti-ai-os/frontend/src/App.tsx
